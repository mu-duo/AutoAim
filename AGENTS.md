# AGENTS.md

## Project
Single-file Python 3.12 desktop app that tracks mouse events (move, click, scroll) and displays them in a Tkinter GUI.  
Entry point: `mouse_tracker.py`

## Setup & Run
- Virtual env: `.venv` (Python 3.12.3)
- Activate: `.\.venv\Scripts\Activate.ps1` or `.\.venv\Scripts\activate.bat`
- Only dependency is `pynput` (installed in `.venv`)
- Run: `python mouse_tracker.py`
